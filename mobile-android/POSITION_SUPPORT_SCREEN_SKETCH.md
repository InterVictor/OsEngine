# Эскиз «Настройки сопровождения позиций»

Статус: предложение, 2026-09-29. [Визуальный эскиз](position-support-screen-sketch.svg). Код Android и VPS не менялся.

## Источник и названия

Кнопка «Сопровождение позиции» в «Чарте» вызывает `RobotsVpsPositionSupportUi` — серверную копию исходного `BotManualControlUi`. Заголовок окна из настольной локализации `TraderLocal.Label85`: **«Настройки сопровождения позиций»**. Все подписи ниже берутся из `TraderLocal`, включая «Проскальз.» и «Лимит ордера только мейкер». Исходные цвета `ThemeDarkOrange.xaml`, положение элементов на планшете — как в настольном окне. Значок инструкции берётся из оригинального `GreenPost.png`.

## Блоки и поля

| Блок | Поля настольного окна |
|---|---|
| **Стоп** | «Включить», «От входа до Стопа», «Проскальз.» |
| **Профит** | «Включить», «От входа до Профита», «Проскальз.» |
| **Закрытие позиции** | «Секунд на закрытие» с чекбоксом, «Макс откат цены» с чекбоксом |
| **Открытие позиции** | «Секунд на открытие» с чекбоксом, «Макс откат цены» с чекбоксом |
| **Ордер на закрытие отозван** | «Реакция» с выбором `Limit / Market`, «Проскальз.» |
| **Общие параметры** | «Тип переменных» (`MinPriceStep / Absolute / Percent`), «Время жизни ордера» (`Specified / GTC / Day`), «Лимит ордера только мейкер» |

Внизу — исходная кнопка **«Принять»**. Зависимости чекбоксов и редактируемых значений сохраняются: мобильный интерфейс не меняет значения сам при переключении группы. Выборы enum остаются точно такими, какие отправляются серверу.

## Телефон

Постоянная шапка с возвратом к «Чарту», терминалом, роботом и вкладкой робота. Далее шесть исходных блоков идут вертикально; форма прокручивается, а «Принять» остаётся доступной внизу. В каждом блоке подпись слева или над полем, значение и чекбокс полностью видимы без горизонтальной прокрутки. При повороте телефона уже введённые значения остаются в форме. Значок инструкции не заменяется придуманной иконкой.

## Планшет

Компактный диалог поверх «Чарта» с двумя колонками, как у `RobotsVpsPositionSupportUi.xaml`: слева «Стоп», «Закрытие позиции», «Ордер на закрытие отозван»; справа «Профит», «Открытие позиции», общие параметры. Кнопка «Принять» и значок инструкции остаются внизу. Если высоты мало, прокручивается содержимое диалога, а не уменьшаются поля до нечитаемого размера.

## Серверное поведение

Окно открывается для конкретных `bot_id` и `tab_name`. `bot_get_position_support` заполняет все поля; до ответа сервера «Принять» недоступно. `bot_set_position_support` отправляет все отредактированные значения и возвращает актуальное состояние. Ввод проходит ту же проверку чисел, что `BotManualControlUi`; успешное сохранение подтверждается ответом VPS, ошибка оставляет окно открытым. При потере связи показан последний полученный набор и время, запись недоступна.

Две тонкости настольной VPS-копии стоит сохранить в плане проверки: список времени жизни ордера сейчас не фильтруется по разрешениям коннектора, а чекбокс maker-only не блокируется для неподдерживающего коннектора. Перед реализацией Android нужно сверить доступные возможности коннектора и поведение ответа сервера, чтобы не выдавать неподдерживаемый выбор за работающий. Кнопка инструкции в настольной VPS-копии пока выводит сообщение о недоступности удалённой справки; значок остаётся на эскизе без вымышленной команды.
