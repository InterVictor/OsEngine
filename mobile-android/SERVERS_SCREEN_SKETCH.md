# Эскиз вкладки «Серверы»

Статус: основной экран реализован 2026-09-30. [Эскиз для телефона и планшета](servers-screen-sketch.svg). Код VPS не менялся. Окно настроек коннектора, закрепление и нижние локальные утилиты остаются отдельными этапами.

## Основа и данные

Источник компоновки — `TabItemControl` в `RobotsVpsLiteClone.xaml(.cs)`. Название в мобильной навигации сокращено по решению пользователя до **«Серверы»**; содержимое относится только к выбранному терминалу. Настольный список создаётся `DataGridFactory.GetDataGridServers()`: **Источник**, **Статус**, пустая узкая колонка для значка закрепления. Справа расположен журнал коннектора с колонками **Время**, **Тип**, **Сообщение**. На планшете сохраняется расположение «список слева / журнал справа»; на телефоне журнал располагается под списком.

Список объединяет `server_management_get_list` и `server_management_get_trade_connectors`: работающие экземпляры плюс доступные типы, исключая `Optimizer`. Настольная VPS-копия ставит закреплённые типы первыми. Для существующего экземпляра `Connect` окрашивает первые две ячейки в `MediumSeaGreen` (`#3CB371`), другой статус — в `Coral` (`#FF7F50`); отсутствующий экземпляр обозначается `Disabled` без цветной подложки. Зелёный маркер самой вкладки загорается, если хотя бы один коннектор выбранного терминала имеет статус `Connect`. Это состояние коннектора, а не SSH.

Журнал берётся через `server_instance_get_log` (`count: 200`). В нынешней настольной VPS-копии выбирается первый подключённый экземпляр, а при его отсутствии — первый экземпляр списка. Мобильный экран должен явно показывать имя источника журнала. На рисунке `BinanceFutures` и статусы — **пример отображения**, не считанные с VPS данные.

## Управление

- Сверху списка остаётся исходный **«поиск...»** по имени источника; стрелки переходят между совпадениями.
- Контекстное меню строки переносит исходные команды: **«Окно настроек»** (уже описано в [эскизе коннектора](CONNECTOR_SETTINGS_SCREEN_SKETCH.md)), **«Закрепить» / «Открепить»**, **«Подключить» / «Отключить»**. На сенсорном экране меню вызывается нажатием `⋮` у строки. Подключение/отключение перечитывает фактический статус с VPS. Для ещё не созданного экземпляра настольная команда активирует тип через `server_management_activate`. Закрепление сейчас хранится настольной копией в локальном `Engine/AttachedServers.txt`; для общего списка на мобильном устройстве нужно отдельно определить синхронизацию, поэтому до этого команда неактивна.
- **«Авто-развёртывание подключений»** читает `server_management_get_auto_connect`, изменение передаёт `server_management_set_auto_connect`; после ответа отображается подтверждённое сервером значение.
- Внизу повторяются настольные кнопки **«Правила поддержки»**, **«Прокси»**, **«Нагрузка на систему»**, **«Доступность серверов»**. В текущей VPS-копии их обработчики открывают локальные настольные окна. На эскизе они показаны ради точности компоновки; для мобильных действий ещё нужны отдельные данные/методы VPS. До их появления они должны быть неактивны с пояснением.

Список опрашивается раз в **5 секунд**, журнал — вместе со списком, только когда открыт этот раздел. Прокрутка при обновлении сохраняется. На телефоне экран прокручивается вертикально, на планшете список и журнал имеют независимую прокрутку. При потере связи действия блокируются и зелёное состояние убирается.
