# Эскиз «Журнал общий»

Статус: по решению пользователя мобильный общий журнал содержит только три раздела; фильтры и полная компоновка остаются по эскизу. [Эскиз для телефона и планшета](community-journal-screen-sketch.svg). Код VPS не менялся.

## Основа и переход

Окно вызывается пунктом **«Журнал общий»** из «Роботы.VPS» выбранного терминала. Источник — `RobotsVpsCommunityJournalUi.xaml(.cs)`, у которого разметка и расчёты наследуют `JournalUi2`. Как и настольная VPS-копия, окно объединяет журналы **всех роботов только выбранного терминала**. Повторный переход возвращает к уже открытому общему журналу этого терминала.

В мобильном общем журнале остаются только **Эквити**, **Открытые позиции**, **Закрытые позиции**. В эквити — серии «Общая прибыль», «Лонг», «Шорт» с согласованными цветами: белый `#FFFFFF`, синий `#00BFFF`, коричневый `#915000`. Разделы «Статистика», «Просадка» и «Объём» из настольной версии исключены из мобильной.

## Компоновка

**Телефон.** Шапка показывает `‹ Роботы.VPS`, имя терминала и «Журнал общий». Три вкладки идут одной горизонтально прокручиваемой строкой. Планируемая кнопка **«Фильтры»** раскрывает период и выбор роботов и бумаг только для этих разделов. Основное содержимое занимает оставшееся пространство. Под графиком эквити показывается легенда.

**Планшет.** Планируемая панель фильтров располагается рядом с содержимым журнала. Справа — те же три вкладки. Число позиции берётся из сервера, а не из номера строки.

Рисунок показывает расположение и условные линии без торговых значений. Названия роботов, бумаги, даты, группы и значения поступают из выбранного VPS-терминала. Телефонная кнопка «Фильтры» открывает те же элементы, что постоянно видны на планшете.

## Источники данных

- Настольное VPS-окно загружает все панели через `RobotsVpsJournalData.LoadAsync(client, null)`, то есть `bot_journal_get_panels` без `bot_name`. При обновлении использует `RobotsVpsJournalData.RefreshAsync(client, null, panelsJournal)`.
- Мобильный журнал использует `bot_journal_get_summary`, `bot_journal_get_equity` и запросы открытых и закрытых позиций. Остальные методы журнала доступны на VPS, но мобильным окном не вызываются.
- В настольном общем журнале группы, множитель `Mult %` и выбор роботов сохраняются в локальном файле `Engine/IsOsTraderJournalSettings.txt`. Для Android это настройки представления выбранного терминала; их хранение потребуется спроектировать до реализации редактирования, не предполагая наличие файла Windows на VPS.
