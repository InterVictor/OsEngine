# Эскиз «Настройка подключения»

Статус: основной экран реализован 2026-09-30. [Визуальный эскиз](connector-settings-screen-sketch.svg). Настройки, экземпляры и лог читаются с VPS; кнопка «Неторговые периоды» открывает отдельный мобильный экран. Код VPS не менялся.

Окно открывается нажатием на коннектор в разделе **«Серверы»** выбранного терминала. Образец — `AServerParameterUi` и его VPS-копия `RobotsVpsServerParametersUi`. Заголовок берётся из `MarketLocal.TitleAServerParametrUi`: **«Настройка подключения BinanceFutures»** для выбранного типа коннектора. Сохраняются исходный порядок блоков, тёмная тема, оранжевые подписи и две вкладки **«Настройки» / «Логирование»**.

## Состав окна

1. **Преднастроенные соединения** — верхняя таблица с колонками **«Имя», «Номер», «Приставка», «Статус»** и исходными действиями в строках. Блок показывается только если коннектор поддерживает несколько экземпляров; при отсутствии поддержки настольное VPS-окно его скрывает.
2. **Имя** текущего экземпляра и **Статус сервера** — над вкладками. Подключённый статус отображается зелёным по исходной теме.
3. **Настройки** — таблица **«Название параметра» / «Значение»**. Строки, порядок, типы редакторов и кнопки приходят с VPS для выбранного коннектора. На рисунке BinanceFutures приведён только как образец: `Public key`, `Secret key`, `Futures Type`, `HedgeMode`, **«Неторговые периоды»**. Эти строки нельзя жёстко прописывать для других коннекторов. Секрет показывается маской. При наличии комментария исходная таблица показывает **«Подробнее»**. Раздел **«Просмотр бумаг»** исключён из мобильной версии по решению пользователя.
4. **Логирование** — исходные колонки **«Время», «Тип», «Сообщение»**.
5. Внизу — **«Подключить»** и **«Отключить»**. Кнопки относятся к выбранному экземпляру коннектора на VPS, не к SSH-соединению телефона.

На планшете остаются две зоны настольного окна: таблица преднастроенных соединений сверху, настройки или лог снизу. На телефоне они идут в том же порядке вертикально; обе таблицы прокручиваются в своих областях, вкладки и нижние кнопки остаются доступны. Для окна не добавляются новые действия.

## Данные и действия

`server_instance_get_params`, `server_instance_get_status`, `server_instance_get_log` загружают содержимое. Изменение параметра отправляется через `server_instance_set_params`; тип `Bool` выбирается как `True/False`, enum — из серверного списка, пароль маскируется. Строка по `button_action=non_trade_periods` открывает исходное окно **«Неторговые периоды»** через `server_instance_get_non_trade_periods` и метод сохранения. Сервер может вернуть строку `button_action=securities`, но мобильный клиент её не показывает и не вызывает.

Подключение и отключение выполняют `server_instance_connect` / `server_instance_disconnect`, затем перечитывают фактический статус. Преднастроенные экземпляры управляются методами `server_instance_create` и `server_instance_delete` с тем же подтверждением удаления, что в настольной копии. При отсутствии связи редакторы и действия блокируются; сохранение считается успешным только после ответа VPS.
