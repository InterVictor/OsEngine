# Эскиз третьего экрана — Роботы.VPS

Статус: согласовано пользователем 2026-09-29; первый рабочий срез реализован. Действующие и ожидающие реализации элементы перечислены в журнале.

## Общий принцип

Экран открывается после выбора `main`, `binance` или другого терминала на предыдущем экране. Его имя постоянно видно в шапке вместе с состоянием SSH и временем последнего успешного обновления. Возврат к списку терминалов меняет контекст данных; данные разных терминалов никогда не объединяются.

Источник структуры: `RobotsVpsLiteClone.xaml` и `RobotsVpsLiteClone.xaml.cs`. Список роботов включает номер, имя, тип, первую бумагу, позиции открытые/закрытые, `Вкл/выкл`, `Эмулятор`, действия `Чарт`, `Параметры`, `Удалить`, `Журнал`. Служебные действия мобильной версии: `Журнал общий`, `Добавить бота`. Нижние разделы: `Позиции` (Активные / Стоп Лимит / Завершённые), `Ордера` (Активные / Завершённые), `Портфель`, `Прайм лог`, `Сервера подключения`.

## Телефон: вариант А — рекомендуемый

- Сверху: `← Терминалы`, имя выбранного терминала, состояние и время обновления.
- В разделе `Роботы` каждая карточка содержит имя, тип, первую бумагу, открытые/закрытые позиции, переключатели `Вкл` и `Эмулятор`; нажатие открывает подробности робота с исходными действиями. Изменение переключателя подтверждается ответом сервера, а затем фактическим значением после повторного чтения.
- `Добавить бота` виден над списком; `Удалить` доступен в подробностях робота с подтверждением. Редкие служебные действия помещаются в `Ещё`.
- Нижняя навигация: `Роботы`, `Позиции`, `Серверы`, `Портфель`, `Ещё`. `Ордера` перенесены в `Ещё` вместе с `Прайм лог` и служебными действиями. Вложенные вкладки позиций и ордеров сохраняются.
- Список прокручивается вертикально. При потере связи последнее значение остаётся с отметкой «Нет связи», переключатели и команды блокируются.

## Телефон: вариант Б — компактный список

Одна короткая строка на робота: имя, тип, бумага, позиции, состояния и стрелка перехода. Переключатели и действия открываются только в карточке робота. Подходит для большого числа роботов, но требует дополнительного перехода для частых переключений.

## Планшет

Таблица повторяет порядок колонок настольной `Роботы.VPS`; действия из широких колонок остаются в строке или раскрываются по нажатию, если ширины недостаточно. Снизу — вкладки `Позиции`, `Серверы`, `Портфель`, `Прайм лог`, `Ордера` с исходными внутренними разделами. Компоновка масштабируется по ширине, а переполненные таблицы прокручиваются без перестановки данных между терминалами.

## Индикация вкладки «Серверы»

Название сокращено до `Серверы`. Вкладка всегда видна в основной навигации. Если внутри выбранного терминала хотя бы один коннектор имеет серверный статус `Connect`, название вкладки и маркер окрашиваются в `MediumSeaGreen` (`#3CB371`) — тот же цвет, которым настольный `RobotsVpsLiteClone` окрашивает подключённый сервер. При отсутствии активных подключений вкладка остаётся обычного цвета. SSH-соединение с VPS само по себе не делает вкладку зелёной; источник индикации — список коннекторов выбранного терминала.

## Следующий минимальный срез после выбора эскиза

Шапка выбранного терминала, получение и обновление списка роботов только для него, состояния связи/пустого списка/ошибки, переход к подробностям робота. Переключатели и действия подключать к существующему серверному API поэтапно и показывать подтверждённое сервером состояние.
