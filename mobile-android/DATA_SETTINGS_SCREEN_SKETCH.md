# Эскиз окна «Подключение потока данных»

Статус: предложение, 2026-09-29. [Эскиз обычной вкладки](data-settings-screen-sketch.svg). Код Android и VPS на этом этапе не менялся.

Кнопка **«Настройки данных»** в «Чарте» открывает для выбранного робота и его вкладки окно с заголовком **«Подключение потока данных»** (`MarketLocal.TitleConnectorCandle`). Образец — приложенный пользователем снимок настольного окна `2026-09-29_15-21-01.png`, а также `ConnectorCandlesUi` и его VPS-копия `RobotsVpsDataSettingsUi`. Сохраняются компактный диалог, оранжевые заголовки секций, тёмные таблицы и исходный порядок полей.

## Обычная вкладка робота

| Блок | Элементы исходного окна |
|---|---|
| Торговый сервер | Выбор сервера |
| Исполнение ордеров | Портфель для операций; «Исполнять сделки в эмуляторе»; тип и значение комиссии |
| Инструмент | Класс бумаг; поиск; таблица выбора бумаги с колонками «Номер», «Тип», «Имя», «Код», «Вкл» |
| Настройки свечей | «Из чего собираем свечи»; «Сохранять трейды в свече»; «Тип свечей»; параметры выбранного построителя свечей |

**Экспирации и страйка в этом шаблоне нет:** в мобильный эскиз эти поля не входят. Внизу — оригинальная кнопка **«Принять»** и значок справки `GreenPost.png`. Таблица параметров свечей создаётся по ответу VPS: «Parameter name» / «Value», с типом редактора для числа, флага или выбора из списка. Таймфрейм является одним из этих параметров, если его предоставляет выбранный построитель. При смене типа свечей параметры нового типа загружаются после сохранения и повторного открытия окна, как сейчас в VPS-копии.

На телефоне тот же узкий диалог адаптируется по ширине: секции остаются на тех же местах, таблица инструментов и таблица параметров прокручиваются внутри своих областей; «Принять» остаётся внизу. На планшете показывается компактный диалог примерно настольной ширины по центру экрана, без растягивания полей на весь планшет. Никаких дополнительных вкладок или команд для этого диалога не вводится.

## Вкладка скринера

Для вкладки скринера настольный «Чарт» вызывает отдельную `RobotsVpsScreenerSettingsUi`, восходящую к `BotTabScreenerUi`. Здесь слева остаются сервер, портфель, эмулятор, комиссия и настройки свечей; справа — **«Инструменты»**: класс бумаг, поиск, «Выбрать все», счётчик выбранных и список с чекбоксами. Вместо общей таблицы параметров построителя здесь присутствует отдельный **«ТаймФрейм»**. На планшете сохраняются две колонки; на телефоне блок инструментов помещается после настроек свечей в прокручиваемой форме. Подробности и отдельный [визуальный эскиз скринера](SCREENER_DATA_SCREEN_SKETCH.md) подготовлены.

## Источник данных и ограничения

- Обычная вкладка: `bot_get_config_tab_simple` → заполнение; `bot_set_config_tab_simple` → сохранение. Вспомогательные списки: `server_management_get_list`, `server_instance_get_portfolios`, `server_instance_get_securities`.
- Скринер: `bot_get_config_tab_screener` и `bot_set_config_tab_screener`; те же источники серверов, портфелей и бумаг.
- Значения для формы загружаются только для конкретных `bot_id` и `tab_name`. До загрузки редактирование и сохранение недоступны. После сохранения показывается полученный ответ VPS; при ошибке окно остаётся открытым. При потере SSH показываются последние данные с отметкой времени, запись недоступна.
- В текущей настольной VPS-копии кнопка справки и настройка максимального спреда для свечей из стакана пока сообщают о недоступности через VPS API. Их не следует изображать как действующие настройки. Для режима `MarketDepth` флаг сохранения трейдов блокируется, как в настольном окне.
