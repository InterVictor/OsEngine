# OsEngine Mobile — облегчённый терминал Android

Цель: управлять уже работающими терминалами OsEngine на Ubuntu VPS с телефона и планшета. Это отдельный клиент; алгоритмы и коннекторы продолжают работать на сервере. Первый экран Android находится в `app/`. Навигация описана в [карте экранов](SCREEN_MAP.md), сборка и проверки — в [TESTING.md](TESTING.md), ход работы — в [журнале](DEVELOPMENT_LOG.md).

## Принципы

- Один SSH-сеанс к VPS, с отдельной галочкой автоподключения при запуске; список терминалов (`main`, `binance`, другие) и их состояние берутся с сервера. Роботы видны только после выбора терминала на отдельном экране «Роботы.VPS»; его имя постоянно отображается в шапке и определяет источник всех данных.
- Сохраняем точные названия из настольной локализации, порядок основных разделов, цветовую систему и иконки OsEngine. На телефоне меняется только компоновка; на планшете используем таблицы и две панели там, где хватает места. В журнале первая вкладка — «Эквити»; линии общей прибыли, лонга и шорта на согласуемом мобильном эскизе — белая, синяя и коричневая.
- Действия над терминалом на экране выбора: только «Перезагрузка». Торговые действия и параметры роботов проектируются внутри «Роботы.VPS» по образцу настольного клиента.
- Источники оформления: `../project/OsEngine/Themes/ThemeDarkOrange.xaml` (тема по умолчанию), `../project/CONTEXT_THEMES.md`, `../project/OsEngine/Images/OsLogo.ico`, `../project/OsEngine/Images/MainWIndow/Themes/DarkOrange/`, `../project/OsEngine/Images/padlockOpened.png` и `padlockClosed.png`. При реализации ресурсы для Android готовятся из этих оригиналов; новые пиктограммы в их стиле согласуются отдельно.
- Базовые цвета DarkOrange: фон `#111217`, оранжевый акцент `#FF5500`, основной текст `#FFEEEFFF`, вторичный текст `#FFA7A8AA`, жёлтая фирменная полоска `#FCEE21`. Для стакана: ask `#FE5400`, bid `#399D36`. Палитра остальных тем берётся из соответствующих словарей `Theme*.xaml`, без ручного переосмысления.

## Текущий этап

В основном ряду «Роботы.VPS» добавлена вкладка «Журнал» с тремя разделами общего журнала выбранного терминала: «Эквити», «Открытые позиции», «Закрытые позиции». Те же три раздела показывает журнал отдельной бумаги скринера. Эквити использует три линии: общая прибыль, лонг и шорт. Вход по одиночному роботу Simple сразу открывает его чарт. Вход по скринеру открывает список торговых бумаг с кнопками «Чарт» и «Журнал» для каждой. Под чартом работают вкладки позиций, стоп лимитов и лога робота. Индикаторы и действия настольного чарта пока остаются по эскизам. Последний Debug APK собран, установлен и проверен на живом `binance` в эмуляторе; детали записаны в журнале.

Вкладка «Портфель» читает портфели всех коннекторов выбранного терминала каждые 15 секунд. На телефоне это карточки портфеля и инструментов, на планшете — таблица с горизонтальной прокруткой. Действия «Сравнить позиции» и «Закрыть» запланированы следующим этапом. «Прайм лог» читает общий журнал выбранного терминала раз в 3 секунды, пока открыт раздел; на телефоне он находится в «Ещё», на планшете — в отдельной вкладке.

Вкладка «Серверы» показывает созданные и доступные торговые коннекторы, их фактические статусы, поиск, серверную настройку авто-развёртывания и журнал первого подключённого коннектора. Список и журнал обновляются каждые 5 секунд, пока раздел открыт. Меню строки открывает настройки коннектора, а также содержит подключение и отключение. Окно настроек читает экземпляры, параметры, статус и лог с VPS; редактирование параметров, управление экземплярами и подключением отправляются серверными командами. «Неторговые периоды» читают девять строк расписания с VPS, показывают общие периоды и семь дней, позволяют менять время, применять преднастройки MOEX и переносить настройки через TXT. Синхронизация закрепления остаётся следующим этапом.

Первые три экрана реализованы в `app/`. Первый SSH-вход выполняется по паролю с подтверждением ключа сервера. Затем приложение регистрирует отдельный ключ устройства в authorized_keys, проверяет вход по нему, шифрует закрытую часть через Android Keystore и удаляет сохранённый пароль. При отзыве ключа следующий вход запросит пароль для повторной регистрации. Экран терминалов читает по SSH systemd-службы OsEngine и загрузку VPS каждые 10 секунд; перезапуск выбранного терминала требует подтверждения. После выбора терминала «Роботы.VPS» читает через его MCP роботов и коннекторы каждые 5 секунд, позволяет менять состояния робота и создавать бота. Вкладка «Позиции» читает три списка с VPS, открывает исходное меню действий и формы дооткрытия/закрытия позиции. Формы читают состояние, стакан и настройки коннектора с VPS; кнопки используют существующие MCP-команды. На момент проверки открытых позиций не было, поэтому торговые команды в эмуляторе не отправлялись. Вкладка «Ордера» читает активные и завершённые ордера выбранного торгового сервера каждые 15 секунд, пока экран открыт; на телефоне вход через «Ещё», на планшете — напрямую. Остальные эскизы ещё не реализованы; создание робота сейчас работает через упрощённые системные диалоги. Debug APK с вкладкой «Позиции»: `app/build/outputs/apk/debug/app-debug.apk`; SSH и чтение трёх разделов позиций проверены на живом VPS 2026-09-30. Серверный и настольный код не менялся.

Карточки терминалов показывают отдельные CPU/RAM и состояние службы. `Connected` означает, что SSH доступен и systemd сообщает `active`; соединение биржевого коннектора здесь не оценивается. Справа на карточке расположены «Открыть» и ниже «Рестарт»; перезапуск требует подтверждения и блокируется на время выполнения. Список прокручивается вертикально.
