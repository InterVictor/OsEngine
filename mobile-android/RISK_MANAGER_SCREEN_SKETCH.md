# Эскиз окна «Риск Менеджер»

Статус: предложение, 2026-09-29. [Визуальный эскиз](risk-manager-screen-sketch.svg). Android-код не менялся.

## Место в порядке окон

После «Торговать» уже подготовлены эскизы «Журнала» и «Параметров». Следующая кнопка в списке «Чарта» — «Риск-менеджер». Предшествующая кнопка **«Настройки торговли бота»** сейчас не имеет общего удалённого окна: `RobotsVpsChartWindow.ButtonStrategIndividualSettings_Click` сообщает о недоступности, потому что `BotPanel.ShowIndividualSettingsDialog` — виртуальный метод с отдельным диалогом у каждой стратегии. В мобильном проекте сохраняется точное название из `TraderLocal.Label43`; универсальную форму для неё не рисуем.

## Основа и точные подписи

Исходное окно `OsTrader/RiskManager/RiskManagerUi.xaml` и его VPS-копия `RobotsVpsRiskManagerUi.xaml` совпадают по полям. Кнопка вызова называется **«Риск-менеджер»** (`TraderLocal.Label46`), заголовок открытого окна — **«Риск Менеджер»** (`Label12`). В форме только исходные элементы:

1. Значок инструкции в верхнем левом углу, как в компьютерной версии.
2. Чекбокс **«Включить»**.
3. Поле **«Максимальный убыток за день в %»**.
4. Список **«Реакция на максимальный убыток»** с серверными значениями `CloseAndOff`, `ShowDialog`, `None`.
5. Кнопка **«Принять»**.

Пояснение для вариантов реакции допустимо рядом со списком, но выбранное и отправляемое значение остаётся исходным enum. `CloseAndOff` на VPS закрывает позиции по рынку и отключает робота при достижении дневного лимита; для остальных вариантов мобильный клиент не добавляет своей реакции.

## Компоновка

**Телефон:** отдельный экран с возвратом в «Чарт» и подписью выбранного терминала/робота. Поля расположены вертикально с достаточной площадью касания; «Принять» внизу. При открытии загружаются значения VPS; до получения ответа кнопка отключена. Длинное название поля переносится, а значение остаётся видимым. Значок инструкции открывает ту же справочную ссылку, если она доступна на Android.

**Планшет:** компактный диалог по центру поверх «Чарта», как настольное окно без изменения размера. Сохраняются взаимное расположение чекбокса, двух строк и кнопки; за ним остаётся тот же выбранный робот.

## Связь с сервером

`bot_risk_manager_get` возвращает `is_active`, `max_drawdown_to_day_percent`, `reaction_type`, `reaction_types`. Кнопка «Принять» отправляет значения через `bot_risk_manager_set`; сервер сохраняет настройки робота. Поле процента проверяется до отправки. После ответа показывается фактическое состояние; при ошибке диалог остаётся открытым и значение не представляется как сохранённое. При потере связи изменение недоступно.

Числовое значение на рисунке — пример компоновки; в рабочем окне оно всегда читается с VPS. Цвета и значок должны происходить из ресурсов настольной темы `ThemeDarkOrange.xaml` и `GreenPost.png`.
