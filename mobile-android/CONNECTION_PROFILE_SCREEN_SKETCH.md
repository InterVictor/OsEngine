# Эскиз экрана «Профиль подключения»

Статус: предложение, 2026-09-29. [Эскиз для телефона и планшета](connection-profile-screen-sketch.svg). Код Android и VPS не менялся.

## Место в навигации

Карта экранов ведёт сюда из списка терминалов. Это настройки **SSH-соединения с VPS**, общие для терминалов `main`, `binance` и других. Экран не относится к биржевому коннектору на вкладке «Серверы».

Компоновка повторяет уже реализованный [первый экран SSH](app/src/main/res/layout/activity_main.xml): логотип OsEngine, тёмный фон, жёлтая полоса, оранжевые подписи и элементы. На телефоне форма прокручивается; на планшете остаётся узкой колонкой по центру. Значения **SSH host** и **SSH user** читаются из `ProfileStore`; **SSH password** здесь не показывается. Галочка называется так же, как на первом экране: **«Автоподключение по SSH при запуске»**. Состояние текущего SSH-сеанса берётся из `RemoteSsh`, отдельно от статусов терминалов и торговых коннекторов.

## Действия

- **«Сменить VPS»** возвращает на существующий первый экран SSH с заполненными адресом и пользователем. Для нового соединения требуется пароль и обычная проверка ключа сервера. Пока новый сеанс не создан, старый не должен изображаться подключением к новому адресу.
- **«Отключиться»** закрывает текущий SSH-сеанс и возвращает на первый экран. Перед переходом нужно выключить автоподключение, иначе следующий запуск сразу восстановит сеанс. Пароль, сохранённый для автоподключения, удаляется существующим `ProfileStore.setAutoConnect(false)`.
- Переключение галочки сохраняет выбор через `ProfileStore`. При включении без сохранённого пароля первый экран запросит его при следующем подключении; экран не показывает пароль и не заполняет его автоматически.

Сейчас `TerminalsActivity` ещё не открывает профиль: в карте переход запланирован, но в приложении нет кнопки вызова. Эскиз задаёт этот переход для следующего этапа реализации. Поля установки терминала, ключи API и серверное развёртывание сюда не переносятся из настольного окна VPS.
