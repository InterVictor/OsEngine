# Эскиз подтверждения перезагрузки терминала

Статус: предложение, 2026-09-29. [Эскиз для телефона и планшета](terminal-restart-screen-sketch.svg). Диалог уже реализован в Android; код и VPS не менялись.

## Исходный диалог

На карточке терминала справа расположены кнопка **«Открыть»** и под ней **«Рестарт»**. `TerminalsActivity.confirmRestart()` показывает модальный диалог с точными строками из `strings.xml`: заголовок **«Перезагрузить терминал?»**, сообщение **«Сервис %1$s будет перезапущен на VPS.»**, кнопки **«Отмена»** и **«Перезагрузка»**. `%1$s` — имя выбранного терминала (`main`, `binance` и т. п.). На рисунке сохранён прежний значок `↻`; фактическая карточка обновлена 2026-09-30.

Диалог одинаков по составу на телефоне и планшете. Фон — экран терминалов с выбранной строкой; остальные элементы затемняются. Никаких дополнительных действий по перезагрузке всего VPS в нём нет.

## После подтверждения

«Отмена» закрывает диалог без команды. «Перезагрузка» вызывает `TerminalsActivity.restart()` только для выбранной службы (`osengine` или `osengine-<имя>`) по действующему SSH-сеансу. На карточке появляется **`Restarting…`**, общая строка показывает **«Перезапуск терминала…»**. При завершении команды приложение показывает **«Команда перезапуска отправлена»** либо сообщение об ошибке и перечитывает список служб. Статус `Connected` возвращается только после ответа нового опроса; сам успешный вызов команды ещё не доказывает, что сервис работает.

При недоступном SSH кнопка «Рестарт» неактивна. Она также блокируется, пока для этой службы продолжается предыдущая перезагрузка.
