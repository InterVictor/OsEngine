# Эскизы окон выбранной позиции

Статус: 2026-09-30 формы дооткрытия и закрытия реализованы в Android и подключены к существующему VPS MCP. Проверены чтение данных, вкладки и блокировка действий для отсутствующей открытой позиции; реальные торговые команды не отправлялись. [Дооткрытие](position-adding-screen-sketch.svg) и [закрытие](position-close-screen-sketch.svg), каждое для телефона и планшета. Серверная часть не менялась.

## Основа и переходы

Источники компоновки и поведения — `PositionAddingUi2` / `PositionCloseUi2` и их удалённые копии `RobotsVpsPositionAddingUi` / `RobotsVpsPositionCloseUi`. Переходы начинаются с **выбранной активной позиции** на вкладке «Позиции» выбранного терминала:

- **«Докупить в выбранную»** открывает **«Окно дооткрытия позиции. Покупаем»** для позиции Buy или **«Окно дооткрытия позиции. Продаем»** для Sell. Первой выбрана вкладка «Лимит».
- **«Переставить стоп»** открывает «Окно закрытия позиции» сразу на «Стоп-Лимит»; **«Переставить профит»** — то же окно на «Профит». Другие вкладки этого окна позволяют закрыть позицию выбранным способом.
- Повторный переход к той же позиции возвращает к её открытому окну. Контекст включает терминал, `bot_id`, вкладку робота, инструмент и уникальный номер позиции. Сведения и объём берутся с VPS и обновляются по исходной логике окна.

## Общая компоновка

В обоих окнах сохраняются сервер, инструмент, номер и состояние позиции, сторона и текущий открытый объём. Окно дооткрытия также явно показывает вкладку робота. Стакан повторяет `RobotsVpsPositionOpenUi`: оранжевые ask над серединой, зелёные bid под ней, столбцы «Сумма / Объём / Цена / Объём». При режиме `BidAsk` показаны только лучшая цена ask и bid; объёмы и глубокие уровни не запрашиваются для отображения. При полном стакане — до 25 уровней на сторону. Нажатие цены заполняет поле цены выбранной вкладки, где оно предусмотрено. Обновление стакана в настольной VPS-копии — каждые 3 секунды, пока окно открыто.

На **телефоне** сведения о позиции находятся под шапкой, стакан — над формой. Высота стакана регулируется; вкладки формы прокручиваются по горизонтали, поля — по вертикали, кнопка действия остаётся внизу. На **планшете** сведения слева, стакан справа, ряд вкладок и форма с действиями — в нижней части, как в настольном диалоге. Палитра и исходная иконка окна берутся из темы OsEngine.

## Дооткрытие позиции

Пять вкладок: **Лимит**, **Маркет**, **Стоп-Лимит**, **Стоп-Маркет**, **Фэйк**. Состав полей:

| Вкладка | Поля и действие |
|---|---|
| Лимит | Цена ордера, Объём; «Купить/Продать лимит ордером» по стороне позиции |
| Маркет | Объём; «Купить/Продать маркет ордером» |
| Стоп-Лимит | Тип активации, Тип жизни заявки, Время жизни свечей, Цена активации, Цена ордера, Объём, Серверный стоп ордер; «Купить/Продать стоп ордером» |
| Стоп-Маркет | Цена активации, Объём, Тип активации, Тип жизни заявки, Время жизни свечей, Серверный стоп ордер; «Купить/Продать стоп-маркет ордером» |
| Фэйк | Дата открытия, Время открытия, Сейчас, Цена ордера, Объём; «Купить/Продать фейк ордером» |

Названия и порядок взяты из `TraderLocal` и `PositionAddingUi2`; конкретная команда меняется вместе со стороной позиции. `bot_position_get_open` возвращает актуальное состояние, `bot_chart_get_snapshot` — сервер и поддержку серверных стоп ордеров, `bot_chart_get_market_depth` — стакан. Действия идут через `bot_position_add`. Флажок серверного стоп ордера доступен только при поддержке коннектором и отражает фактическую настройку VPS.

## Закрытие позиции

Шесть вкладок: **Лимит**, **Маркет**, **Стоп-Лимит**, **Стоп-Маркет**, **Профит**, **Фэйк**. Для Лимит/Маркет/Стоп-Лимит/Стоп-Маркет/Фэйк сохраняется поле объёма закрытия и исходное действие **«Весь открытый объём»**, которое подставляет текущий объём. Поля и кнопки:

| Вкладка | Поля и действия |
|---|---|
| Лимит | Цена ордера, Объём; «Закрыть лимит ордером», «Отозвать» |
| Маркет | Объём; «Закрыть маркет ордером» |
| Стоп-Лимит | Цена активации, Цена ордера, Серверный стоп ордер, Объём; «Выставить стоп ордер», «Отозвать» |
| Стоп-Маркет | Цена активации, Серверный стоп ордер, Объём; «Выставить стоп-маркет ордер», «Отозвать» |
| Профит | Цена активации, Цена ордера; «Выставить профит ордер», «Отозвать» |
| Фэйк | Дата закрытия, Время закрытия, Сейчас, Цена ордера, Объём; «Закрыть фэйк ордером» |

При открытии через «Переставить стоп/профит» активируется соответствующая вкладка **этого же окна**, без отдельного выдуманного диалога. Указанные команды существуют в VPS API как `bot_position_close_at_limit/market/stop/stop_market/profit` и `bot_position_revoke_close_orders/stop/profit`. В текущей VPS-копии фейк-закрытие отправляется как `bot_position_close_at_market` с `is_fake=true`; отдельного параметра времени закрытия сервер пока не принимает. Перед реализацией Android поле времени следует показывать согласно исходной форме, сохраняя это ограничение API.

Значения на рисунках иллюстрируют расположение. Отправка возможна только при живом соединении и после проверки полей; результат перечитывается с VPS.
