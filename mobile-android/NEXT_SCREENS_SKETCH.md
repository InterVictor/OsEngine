# Следующие окна: «Параметры робота» и «Журнал робота»

Статус: эскизы на согласование, 2026-09-29; названия и цвета журнала исправлены по замечанию пользователя. Код Android и VPS не менялся. Визуальная схема: [next-screens-sketch.svg](next-screens-sketch.svg).

Общее правило: подписи брать из локализации настольного OsEngine, цвета — из соответствующих ресурсов темы. Для тёмной оранжевой темы `ThemeDarkOrange.xaml` цвет заголовков вкладок, фона и фирменной полосы переносится без произвольной замены.

## 1. Параметры робота

Основа — `StrategyParametersUi` через уже существующую VPS-копию `RobotsVpsParametersUi.xaml(.cs)`. Открывается из карточки робота или из «Чарт → Управление → Параметры». В шапке: `‹ Роботы.VPS` или `‹ Чарт`, терминал, имя робота, состояние связи.

**Вкладки формируются строго по ответу VPS**: первая из параметров без `tab_name` с меткой `first_tab_label`, затем группы с их `tab_name`, далее `custom_tabs`. Для FF143 это могут быть `Base / Base1 / Base2 / Regime switch / Spectrum`, как на настольном снимке, но Android не подставляет эти названия другим стратегиям. Если сервер вернул пустую пользовательскую вкладку, показывать её название и явное сообщение об отсутствии удалённого содержимого, как делает текущая настольная копия.

На телефоне горизонтальная строка вкладок прокручивается отдельно. Под ней — двухколоночные строки «Название параметра / Текущее значение». Число открывает числовой редактор с `start/stop/step`, строка со списком — выбор из серверных значений, `Bool`/`CheckBox` — чекбокс, `TimeOfDay` — редактор времени, `DecimalCheckBox` — совместные чекбокс и число. `Label` и `Button` сохраняют исходный вид и смысл. Стили отдельных строк, цвета и разделители берутся из `parameter_designs`, насколько они передаваемы Android. Список прокручивается вертикально, шапка с вкладками и действия внизу остаются на месте.

Нижние действия повторяют оригинал: **Сохранить**, **Загрузить**, **Обновить**, **Принять**. «Сохранить/Загрузить» экспортируют и импортируют JSON через системный выбор файла Android. «Обновить» отправляет редактируемые значения на VPS, оставаясь в окне; «Принять» отправляет значения и закрывает окно после успешного ответа. Изменённые, но ещё не отправленные значения обозначаются локально; при уходе с экрана предлагается сохранить или отбросить их. Запись на VPS только через `bot_set_params`, затем серверное чтение для сверки.

На планшете сохраняется ширина двух колонок, горизонтальные вкладки сверху и четыре действия снизу. Форму можно прокручивать при большом числе параметров; ширина не раздувается из-за длинных имён. Источник: `bot_get_params`, `bot_set_params`, для кнопок параметров `bot_click_param_button`. Нестандартные локальные кнопки, например панель режима FF143, требуют отдельного переноса клиентского окна; обычный вызов `bot_click_param_button` не должен подменять его.

## 2. Журнал робота

Решение для мобильной версии: журнал дочерней бумаги скринера содержит только «Эквити», «Открытые позиции» и «Закрытые позиции». Эти три вкладки работают; другие разделы настольного журнала в мобильное приложение не включаем.

Основа — `JournalUi2` / `RobotsVpsJournalUi.xaml`, в настольной VPS-копии данные приходят из `bot_journal_get_panels` и затем отображаются исходными компонентами журнала. Контекст выбранного робота и терминала виден постоянно; из «Чарта» дополнительно сохраняется конкретная вкладка робота.

Порядок мобильных вкладок: **Эквити**, **Открытые позиции**, **Закрытые позиции**. В «Эквити» сохраняются серии **Общая прибыль / Лонг / Шорт**: белый `#FFFFFF`, синий `#00BFFF`, коричневый `#915000`. У позиций сохраняется уникальный номер сервера.

В исходном `RobotsVpsJournalUi.xaml.cs` фактическая линия шорта берёт `JournalShortColor=#FF8C00`, а его цветовой образец в `ThemeDarkOrange.xaml` — коричневый `JournalSwatchShortBrush=#915000`. По уточнению пользователя мобильный эскиз использует коричневый. Перед кодом графика нужно согласовать эти два ресурса с компьютерной версией и не вводить третью палитру.

На телефоне первая строка — шапка, вторая — три вкладки с горизонтальной прокруткой. График или позиции занимают остальную область. Планируемые фильтры периода и бумаги относятся только к этим трём разделам. На планшете журнал показывает те же три вкладки.

Источник исходных позиций — `bot_journal_get_open_positions`, `bot_journal_get_closed_positions` и для текущих открытых позиций дочерней вкладки `bot_position_get_open`. Линии эквити строятся из этих позиций с исходным множителем `mult_to_journal`. Вне открытого окна журнал не опрашивается.

## Порядок реализации после согласования

1. «Параметры»: реальные серверные вкладки и отображение всех типов параметров; затем безопасная отправка изменений и импорт/экспорт JSON.
2. «Журнал»: экран и фильтры; затем позиции, метрики и графики по исходному порядку вкладок.
3. Оба окна открываются из существующего списка роботов. Возврат сохраняет выбранный терминал и ранее загруженный список.

Числа и названия роботов на визуальной схеме — только иллюстрация расположения. В рабочем приложении используются значения выбранного VPS-терминала.
